# Mood Café

เว็บร้าน Mood Café สำหรับแนะนำเครื่องดื่มตามอารมณ์ สั่งซื้อ และติดตามคำสั่งซื้อ

เปิด PowerShell หรือ Terminal ใน VS Code แล้วรัน ทีละบรรทัด โดยกด Enter หลังแต่ละบรรทัด:

1. cd "D:\Downloads\Mood-Cafe-main\Mood-Cafe-main"

2. py -m pip install -r requirements.txt

3. py app.py

เมื่อบรรทัดสุดท้ายทำงาน ให้เปิดเบราว์เซอร์ไปที่:
http://127.0.0.1:5001/

หากยังไม่มี Flask ให้รัน python -m pip install -r requirements.txt 
ถ้าติดตั้งแพ็กเกจไว้แล้ว ข้ามบรรทัดที่ 2 ได้ และตอนจะปิดเว็บให้กลับไปที่ Terminal แล้วกด Ctrl + C
